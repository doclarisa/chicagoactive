# Bloomingdale wave — review checklist

Context: Bloomingdale had 1 pre-existing listing (Michael A. Miliotti
Senior Center, Bloomingdale Township) but no `/city/bloomingdale` hub
page. This wave adds 1 verified venue, clearing the bar, and adds
Bloomingdale to `lib/cities.ts` for the first time. This is the last
commit in `multi-area-wave-14`, so it also carries the CITIES entries for
all 3 areas built this wave (Glendale Heights, Villa Park, Bloomingdale).

## Dropped this wave

- **Carpentersville** — the one promising lead, a Kane Senior Council chapter ("Seniors of Carpentersville"), meets at the same address (665 Barrington Ave) as the pre-existing Dundee Township Park District listing — not a distinct venue. Carpentersville's actual public library (Dundee Township Public Library) is 2 miles away in Dundee — a true-address situation that wouldn't count toward Carpentersville's own bar.
- **McHenry** — the strongest-looking candidate, McHenry Township Senior Center, has a true address in Johnsburg (3519 N Richmond Rd, Johnsburg, IL), not McHenry — same true-address issue. McHenry's own Parks & Recreation Dept has no confirmed senior-specific programming, only general "all ages" activities. **Note for a future wave:** Johnsburg is already in the backlog with 1 listing — McHenry Township Senior Center would be a strong second venue there.
