# Oak Brook wave — review checklist

Context: Oak Brook had 1 pre-existing listing (Oak Brook Park District Pioneer
Programs) but no `/city/oak-brook` hub page. This wave adds 2 verified venues,
clearing the bar, and adds Oak Brook to `lib/cities.ts` for the first time.

## New listings added (2)

### 1. Oak Brook Public Library — Adult Services
- **sourceUrl:** https://www.oak-brook.org/library
- Book clubs, tech/digital-literacy help, study/meeting rooms, museum passes.
- **Verify:** specific senior-only program names weren't confirmable via the live events calendar during research — check before citing specific class names.

### 2. Graue Mill and Museum
- **sourceUrl:** https://www.dupageforest.org/graue-mill
- A free 1852 water-powered gristmill, Forest Preserve District of DuPage County. Open Wed-Sun 10am-4pm, mid-April through mid-November.
- **Verify:** older cached sources showed a paid admission structure ($5/$4); the current official page states free — treated as current since it's the more recent official source, worth a quick re-check.

## Excluded

- **York Township Senior Center** — real, well-documented, free/low-cost, and explicitly serves Oak Brook residents, but its true physical address is **1502 S. Meyers Road, Lombard, IL** — not Oak Brook. Per this site's true-address convention, this belongs on Lombard's own page (already a built hub), not Oak Brook's. Flagging as a good candidate for a future Lombard enrichment pass, not added anywhere this wave.
- **Mayslake Peabody Estate** — Forest Preserve District cultural site, but currently closed for master-plan construction with no confirmed senior programming. Worth revisiting once the closure lifts.
